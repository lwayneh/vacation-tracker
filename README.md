# Awesome Vacation Tracker

### Purpose of Awesome Vacation Tracker
" The Awesome Vacation Tracker mobile application is a great vacation schedule option designed to help you, the traveler, with tracking any vacations and excursions you got planned or are thinking of booking in the future. In short, it allows you to create a vacation list. But it also provides you with an interface to view and modify each vacation you entered and to save many other important details. It even allows you to create, edit and associate multiple excursions with a vacation. What's more, the Awesome Vaction Tracker provides you with the ability to share newly booked vacation with your friends and family via several supported social media platforms. It also lets you set up notifications and alerts for important dates related to your exploration journey."

The Awesome Vaction Tracker is a multiple-screen tracking mobile application written in Java.
This repository includes a generated and tested signed APK, deployable using Android 15.

### Tools and Technologies:
- Android Gradle Plugin, version 8.9.0
- Gradle, version 8.11.1
- Android Studio, Meerkat
- Android 15 "Vanilla Ice Cream"
- Android SDK, 35

### Notable Dependencies:
- Room library: The Room persistence library provides an abstraction layer over SQLite to allow for more robust database access while harnessing the full power of SQLite
- SQL Lite for the locally stored database

### APK Instructions:
1. Download and install Android Studio [here](https://developer.android.com/studio).
2. Download the signed APK [here](https://gitlab.com/wgu-gitlab-environment/student-repos/lhagan4/d308-mobile-application-development-android/-/raw/finalbranch/TaskE.SignedAPK/release/app-release.apk?inline=false).
3. In your Android Studio application, click on File -> Profile or Debug APK.
4. From within the "Select APK File" window, find the apk file on your local desktop.
5. In the "APK Import" window, click on "Use New Project".
6. Once the APK has finished setting up, a new Android Studio window should pop up. From the Toolbar, click on the green arrow button.
7. In the "app-release" window, click again on the green arrow button in the Toolbar. It will take a minute or two for the target device (emulator) to go boot up, install the application and open it on the android device emulator screen.

That's it! Enjoy our preview of the Awesome Vacation Tracker application.


### How to Use the Awesome Vacation Tracker
- Go to the vacation list screen to view your list of scheduled vacations.
- Tap the kebab menu button "(⋮)" to add a new vacation.
- Select a vacation from the list to view its details.
- On the vacation detail screen, tap the kebab menu button again, then:
    - Tap the "Share This" option to send the exciting news to yourr contacts.
    - Tap the "Notification Setup" option to set a reminder for the vacation start date.
    - View or add related excursions.
- From the excursion list, tap an excursion to:
    - View its details.
    - Set a notification for its scheduled date.
    - Modify or delete vacations and excursions as needed!
